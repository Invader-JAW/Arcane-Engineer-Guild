## What I Built

I created the campaign's persistent world, including its repository structure, rules, character records, journals, project areas, image storage, and reusable templates.

## Permanent Benefit

This system turns future learning and project work into organized, version-controlled evidence. It creates a repeatable process for receiving quests, documenting completion, recording Guild Master feedback, and tracking real-world progress.

## What I Learned

- Obsidian can use a normal Git repository as a vault.
- Markdown files remain readable inside both GitHub and Obsidian.
- Git preserves the history of the campaign.
- Templates reduce the effort required to document future work.
- Preparation that improves future execution is meaningful progress.

## What Was Difficult

Learning how Obsidian handles templates and dated journal notes required additional setup and practice.
