### ### Objective

Learn why **health checks** matter in Docker Compose and implement one yourself.

### Tasks

1. Read about Docker Compose health checks and `depends_on` with `service_healthy`. The official Docker documentation walks through the concept and explains how startup ordering works.
2. Create a small `docker-compose.yml` with:
    - A web service
    - A Redis service
    - A Redis health check
    - `depends_on` using `condition: service_healthy`
3. Bring the stack up:
    
    ```
    docker compose up
    ```
    
4. Verify:
    
    ```
    docker ps
    docker inspect <container>
    ```
    
    Look for the container's health status.
